# 文档档案索引（归档目录）

用途：集中存放历史版本、阶段性总结、清理与重组类文档，避免主目录重复维护。

## 分类
- 文档重组与清理：`docs/archive/duplicate-docs-cleanup-*`、`docs/archive/documentation-docs-cleanup-*`
- 部署文档历史：`docs/archive/deployment-docs-cleanup-*`
- 测试文档历史：`docs/archive/testing-docs-cleanup-*`
- 过时文档归档：`docs/archive/obsolete-docs-*`
- 进度与周报：`docs/archive/progress-reports/*`、`docs/archive/completed-weeks/*`
- AI 配置历史：`docs/archive/ai-config-*/`

## 使用规则
- 归档文件只保留历史参考，不在主目录复用或链接正文。
- 新增归档请按以上分类命名，保留原始时间戳与背景说明。
- 若主目录存在重复信息，应保留单一来源页面，并将重复页迁移至此目录。
