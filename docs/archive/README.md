# docs/archive/ — 归档区说明

> 历史快照与审计留存区（非权威入口）

**最后更新**: 2026-02-10
**维护者**: 技术负责人
**状态**: 已发布（已精简）

---

## 目的

`docs/archive/**` 用于保存历史进度报告、清理记录等历史快照。

**权威文档入口**: [docs/DOCUMENTATION-INDEX.md](../DOCUMENTATION-INDEX.md)

## 目录结构

- `historical/` - 统一历史归档
  - `reports/` - 进度报告（周报、月报已合并）
  - `obsolete-docs*/` - 已废弃文档
  - `old-issues/` - 历史问题记录
  - `test-fixes/` - 测试修复记录
  - `todo-tracking-*/` - TODO 跟踪记录
  - 其他历史文档

## 归档原则

1. **简洁优先**: 历史报告只保留关键里程碑
2. **定期清理**: 每季度清理一次过期文档
3. **不修旧链**: 历史快照保持原样，不修复断链
