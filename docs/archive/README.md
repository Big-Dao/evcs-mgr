# docs/archive/ — 归档区说明

> 历史快照与审计留存区（非权威入口）

**最后更新**: 2026-01-12  
**维护者**: 技术负责人 / AI Assistant  
**状态**: 已发布  

---

## 目的

`docs/archive/**` 用于保存阶段性报告、清理记录、已废弃/过时文档的历史快照，方便追溯与审计。

权威、可依赖的文档入口始终是：`docs/DOCUMENTATION-INDEX.md`。

## 处理策略（重要）

- **历史文档不修链**：归档区中的历史快照可能包含断链、过时引用、与当前代码不一致的描述；这些内容保持原样以保留当时语境。
- **本次归档必须修链**：在某一次归档操作中被移动/新增到归档区的文档，应在同一次变更中修复其自身的相对链接，确保在新位置可自洽阅读。
- **不把归档区当文档入口**：归档区不应被当作新同学的学习入口，也不参与日常“文档必须零断链”的质量门禁。

## 目录约定

- `documentation-history/`：文档治理、清理计划/总结、审计报告等。
- `progress-reports/YYYY-MM/`：阶段性进度报告归档。
- `old-issues/`：历史问题/修复记录（仅供追溯）。
- `obsolete-docs-YYYY-MM-DD/`：已废弃/不再维护但需要留存的文档快照。
