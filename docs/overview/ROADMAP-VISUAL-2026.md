## 5. 风险预警与应对

### 5.1 红色预警（立即处理）

```
🔴 协议栈对接超期（> 5天）
   → 缓解: 降低真实对接范围，保留部分 mock

🔴 测试覆盖率无法达标（< 85%）
   → 缓解: 聚焦核心业务逻辑，工具类适度放宽

🔴 性能压测不达标（TPS < 300）
   → 缓解: 立即启动数据库优化/缓存策略
```

### 5.2 黄色预警（关注跟踪）

```
🟡 人力资源不足
   → 缓解: 调整优先级，延后 P3 任务

🟡 evcs-user 工期延误
   → 缓解: 分阶段上线，优先核心功能

🟡 第三方服务不稳定
   → 缓解: 熔断降级已就位，影响可控
```
