## 📋 任务优先级分类

### 🔴 P0 - 多层级多租户分级治理（新增需求，1-2周）

**目标**: 支持租户层级（L0/L1/L2+）的分级管理，并保证跨层访问与审计可控。

**需求基线**:

- [docs/architecture/requirements.md](../architecture/requirements.md)
- [docs/architecture/TENANT-CONTEXT-ASYNC-RFC.md](../architecture/TENANT-CONTEXT-ASYNC-RFC.md)

**具体任务（按最小可交付拆分）**:

- [x] 定义并固化租户层级模型与状态联动策略（禁用上级 → 下级不可用；恢复策略明确）
- [ ] 实现“上级管理下级”的管理能力边界（用户/配额/能力开关），并记录审计日志
- [x] 约束跨层数据访问：仅允许显式范围的只读统计/查询（`tenantScope=SELF_AND_DESCENDANTS`），跨层写默认禁止
- [ ] 集成测试覆盖：跨层只读、越权拒绝、禁用联动、异步上下文传播

**验收标准**:

- 上级可管理下级，下级不可越权；跨层访问必须显式声明且可审计
- 任意异步/消息消费不得出现跨租户写入
