## 限制说明

### ❌ 我不能做的事情

1. **访问外部系统**
   - 我不能访问生产数据库或外部 API
   - 我只能基于您提供的信息工作

2. **执行某些操作**
   - 我不能直接部署代码到生产环境
   - 我不能直接访问 GitHub 进行 PR 操作（但可以通过工具间接操作）

3. **替代人工决策**
   - 架构重大变更需要团队讨论
   - 数据库结构变更需要仔细评估
   - 安全策略需要专业审查

1. **提供清晰的需求**
